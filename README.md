# deckone-site

Site public de Deck One (https://deckone.io), hébergé sur GitHub Pages.
Dépôt **public** volontairement : il ne contient que ces pages statiques, aucun secret.

- `index.html` : page d'accueil
- `confidentialite/` : politique de confidentialité (URL à donner à Apple)
- `mentions-legales/` : mentions légales (obligatoires en France)
- `assets/` : style Aero citron et police DM Sans (licence SIL Open Font License)
- `CNAME` : nom de domaine pour GitHub Pages

Les passages surlignés en citron `[À COMPLÉTER]` / `[À VÉRIFIER]` sont à remplir avant de donner l'URL à Apple.
La politique doit rester identique à `docs/politique-confidentialite.md` du dépôt de l'app.
